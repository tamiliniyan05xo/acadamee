#  Academe - Student Learning & Course Management System

A full-stack web application that allows students to enroll in courses, track progress, and manage their learning journey.

---

##  Features

-  User Authentication (Login / Signup)
-  Course Enrollment System
-  Progress Tracking
-  User Profile Management
-  Dashboard with statistics
-  Certificate on course completion

---

## Tech Stack

### Frontend
- React.js
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (or LocalStorage for demo)

##  Installation & Setup

###  Clone the repository


git clone https://github.com/tamiliniyan05xo/academee.git

cd academee


---

###  Install dependencies

#### Frontend


cd frontend
npm install
npm run dev


#### Backend


cd backend
npm install
node server.js

GET /api/courses
